# CarBridge 0.52 — профиль HeadSwap

Отдельный APK с интерфейсом CarBridge Offline 0.52 для HeadSwap Desktop 0.5.0, Android 13+. Проект самостоятельного CarBridge не изменялся.

## Исправления 0.52-headswap.2

- Удержание значка в доке открывает меню «Запустить / Остановить…». Избранное меняется отдельным явным действием меню. Удержание плитки домашнего каталога по-прежнему меняет избранное.
- Profile API v1 не имеет команды force-stop. «Остановить…» открывает системную страницу выбранного приложения на телефоне; остановку нужно подтвердить там. Это не имитация успешной остановки.
- Музыка сначала читается через SDK HeadSwap. Если трек не передан, профиль может использовать медиасессию Android через отдельно выданный пользователем доступ CarBridge к уведомлениям. Без этого согласия резервный источник не читается.
- В музыкальной карточке добавлена кнопка настройки доступа. Для работы через HeadSwap ему нужны и согласие на музыку у профиля, и собственный доступ к уведомлениям Android. Локальный вариант CarBridge использует своё отдельное разрешение.

## Скачать

Готовый APK прикреплён к релизу `v0.52-headswap.2` этого репозитория. Требуется HeadSwap Desktop 0.5.0 и Android 13+.

## Установка

1. Установить совместимый HeadSwap Desktop 0.5.0 и APK этого профиля на один телефон, в одного пользователя Android.
2. Остановить текущую проекцию. В HeadSwap открыть **Профиль → CarBridge 0.52** и подтвердить выбор. Для плеера предоставить профилю доступ к музыке.
3. Активировать HeadSwap обычным способом и подключить ГУ по USB.
4. Для шторки уведомлений открыть настройки CarBridge и включить отдельный доступ к уведомлениям в Android на телефоне. Это добровольное разрешение: каталог и музыка работают независимо от него.

Пакет: `com.example.carbridge.headswap`. Точка входа: `com.example.carbridge.ProfileActivity`. MODE_ID: `carbridge`, Profile API v1. Новое приложение устанавливается рядом с исходным CarBridge и примером `com.headswap.local.carbridge.profile`; это не обновление приложенного пользователем APK.

При открытии значка на телефоне доступен просмотр интерфейса и локальные настройки. Запуск приложений, команды плеера и управление телефоном требуют активного сеанса HeadSwap.

## Управление

- Домашний экран: сетка приложений с оформлением и иконками из CarBridge 0.52. Нажатие открывает приложение через HeadSwap. Удержание добавляет или убирает его из избранного.
- Док высотой 39 dp: «Назад», «Домой», каталог приложений CarBridge, музыка, экран телефона, избранное. Далее — недавние запросы запуска, сетевые индикаторы, число уведомлений, часы и заряд телефона. Запрос запуска не подтверждает, что Android уже разместил приложение: подтверждения и ошибки размещения обрабатывает HeadSwap.
- Музыкальная панель: 30% ширины экрана, обложка и текущие метаданные из SDK либо разрешённой медиасессии Android, предыдущий трек, воспроизведение/пауза, следующий. Кнопка ⇄ меняет сторону. Крестик и свайп к внешнему краю скрывают панель. Метаданные не сохраняются на диск.
- Избранное: узкая скруглённая панель, расширение для выбора приложений, смена стороны, закрытие крестиком, касанием снаружи или свайпом к краю. Удержание значка убирает его из списка. Выбор и сторона сохраняются.
- На домашнем экране есть зелёные ручки панелей. В окне стороннего приложения избранное открывается звездой в доке: края его окна принадлежат хосту.
- Нажатие на часы/индикаторы открывает шторку уведомлений. Можно прочитать текст, открыть приложение через HeadSwap или убрать доступное для удаления уведомление. История уведомлений на диск не записывается.
- В настройках можно автоматически скрывать док через 6 секунд работы в приложении. Снизу остаётся ручка для восстановления. Резерв её высоты передаётся HeadSwap.

## Адаптация к API хоста

HeadSwap управляет USB/CarLife, дисплеями, размещением приложений, вводом, аудио и HUD. Профиль не запускает собственный ADB, scrcpy, службу захвата или overlay. Собственная клавиатура CarBridge и инъекция текста не перенесены: используется штатная клавиатура приложения, поддержанная HeadSwap.

Открытие избранного или шторки временно скрывает область стороннего приложения через `setDashboardLayout`, сохраняя его задачу. Закрытие возвращает область. Произвольные всплывающие окна поверх чужого приложения, принудительная остановка его процесса и доступ к микрофону отсутствуют в публичном Profile API v1. Навигационные подсказки на приборке обслуживает HeadSwap.

Окно удержания USB-аудио для Алисы из самостоятельного CarBridge 0.52 сюда не перенесено: выходной маршрут принадлежит HeadSwap. Поведение Алисы, звука, клавиатуры и конкретного ГУ следует проверить на устройстве.

## Сборка

JDK 17, Android SDK Platform 34, Gradle 8.14.5 (wrapper), AGP 8.5.2, Kotlin 1.9.24. SDK профиля использует API Android, доступные в compileSdk 34; minSdk 33 сохранён. При первой сборке требуется доступ к репозиториям зависимостей. Путь к Android SDK задаётся в локальном `local.properties` (`sdk.dir=...`) или переменной `ANDROID_HOME`.

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:assembleDebugAndroidTest
.\gradlew.bat :sdk:testDebugUnitTest :app:testDebugUnitTest
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`.

При локальной проверке на эмуляторе можно установить оба APK и выполнить:

```powershell
adb -s EMULATOR_SERIAL install -r app/build/outputs/apk/debug/app-debug.apk
adb -s EMULATOR_SERIAL install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s EMULATOR_SERIAL shell am instrument -w com.example.carbridge.headswap.test/com.example.carbridge.ProfileVerification
```

Инструментальные тесты используют подставной Binder хоста. Они проверяют протокол, жизненный цикл и интерфейс, но не заменяют проверку реального HeadSwap и автомобиля. Тестовый хост не входит в основной APK.

Модульные тесты SDK заимствованы из того же исходного тега HeadSwap; в двух выражениях `String.repeat` заменён эквивалентом для компиляции Java 8. Дополнительно есть проверки ограничений геометрии дока и каталога при разных размерах экрана и DPI.

## Источники

Интерфейс, атлас значков, `HuPanelIcons`, `HuStatusIcon` и размер дока перенесены из локальных исходников CarBridge Offline 0.52. Экран профиля и адаптер жизненного цикла написаны для этой интеграции.

SDK скопирован без изменения Java/AIDL из HeadSwap Desktop v0.5.0, commit `080bb92364ae9a31f6740562f3d55688fc351e5d`: `sdk/desktop-panel-v1/src/main`. Изменены только настройки сборки SDK: compileSdk 34, Java 8 bytecode. Исходная лицензия GPLv3 — `third_party/HEADSWAP-LICENSE`.

Исходный репозиторий: https://github.com/SadykovIV/headswap_desk/tree/v0.5.0

Пробный APK подписан локальным debug-ключом. Для дальнейших обновлений этого пакета необходимо сохранить тот же ключ и увеличивать versionCode.
